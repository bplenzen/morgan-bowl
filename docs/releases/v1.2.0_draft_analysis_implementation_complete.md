## What Was Fixed

### 1. Look-Ahead Bias Elimination ✅

**Problem (Before):**

- Draft grades recalculated replacement levels using current season performance
- If QB12 at draft (Jordan Love) performed poorly, replacement level dropped
- This made teams who drafted Love look better unfairly
- Grades changed when new weeks were ingested

**Solution (After):**

- Created `int_draft_day_baseline.sql` using ONLY preseason rankings
- Frozen parameter file: `data/draft_day_parameters_2025.yml`
- Replacement player IDENTITY locked at draft day (QB12 = Jordan Love)
- Replacement player PERFORMANCE updates weekly (fair comparison)
- Status field: "FROZEN - Never recalculate"

**Verification:**

- Test: `test_draft_parameters_frozen.sql` ✅ PASSING
- Confirms replacement ranks never change (QB12, RB28, WR32, TE12)
- Validates scarcity multipliers match frozen parameters

### 2. Multiplicative Risk Model ✅

**Problem (Before):**

- Risk factors were averaged: `(availability + volatility + position) / 3`
- RB who missed 30% of games and was volatile had same risk as WR who only had volatility
- Didn't properly compound multiple risk dimensions

**Solution (After):**

- Created `int_player_risk_factors.sql` with multiplicative formula
- `Risk Factor = Availability × Volatility × Position Fragility`
- Availability: games_played / 17 (expected games)
- Volatility: CV mapped to [0.7, 1.0] scale
- Position Fragility: RB=0.85, WR=0.95, TE=0.90, QB=1.00
- Multiple risks compound properly (0.8 × 0.8 = 0.64, not 0.8)

**Impact:**

- RBs who missed games AND were volatile get much lower scores
- Properly reflects true risk of multi-dimensional issues
- Position fragility priors baked into model

### 3. ADP as Projection Proxy (Scientifically Valid) ✅

**Problem (Before):**

- Concern that ADP was "market sentiment" not projections
- No access to raw preseason PPG projections (Sleeper doesn't provide)

**Solution (After):**

- Documented that ADP = aggregated expert consensus
- ADP incorporates FantasyPros, ESPN, Yahoo expert projections
- Market adjusts to expert rankings (drafters use same sources)
- Validated via `data/draft_day_parameters_2025.yml` documentation

**Data Sources:**

- Sleeper API: Confirmed no preseason season-long projections
- FantasyPros: Historical data requires paid subscription (~$50/yr)
- Preseason ADP CSV: Real data from actual league draft preparation
